# Run

Run with `npm run dev`

# Deploy

Vercel deploys any push to master to https://www.georgep.xyz (DNS is in Cloudflare). Requires Node 22+ (`.nvmrc`).

```
src/content/blog - put markdown in here for automagic blog posts
notebooks        - code for making graphs etc
public           - complex blobs of codes for e.g. dinowar and lunee or charts

```

# Tooling

[Astro](https://docs.astro.build) + Tailwind + daisyUI, with React for interactive components.
